# Rolecall brand

**Name.** *Rolecall*, a play on "roll call": before every deploy, call every role and check what it can make your agent do.

**Mark.** A 3×3 grid is the permission matrix (roles × tools). Eight green cells hold. One coral cell is the violation Rolecall caught.

| Token | Hex | Use |
|---|---|---|
| Ink | `#12131A` | Mark background, dark surfaces |
| Mint | `#3DDC97` | Pass / held |
| Coral | `#FF5A5F` | Fail / violation |
| Amber | `#FFB020` | Warning (model-only defense) |
| Violet | `#7C5CFF` | Brand accent, links, focus |

Files: `logo-mark.svg` (icon/favicon), `logo-wordmark.svg` (uses `currentColor` for the text, so it works on light and dark).

**Tagline:** *Who can make your agent do what? Find out before your users do.*
